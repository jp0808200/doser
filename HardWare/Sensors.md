# Liquid sensor wiring

## 8mm line liquid sensor XKC-Y29d-D8-NPN

Brown: Power 12V-24VDC

Blue: GND

Yellow: Signal (open collector) pulls when liquid detected

Connector: 4-pin JST

## Tank level sensor XKC-Y23A-V

Brown: +5VDC

Blue: GND

Black: Signal (+5VDC when liquid detected)

Connector: 3-pin JST

## Flow sensor Digiten FL-308T

Red: +3.3VDC

Black: GND

Yellow: Signal (3.3V pulse)

Connector: 3-pin JST
